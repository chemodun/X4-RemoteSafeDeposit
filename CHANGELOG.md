# Changelog

## [1.03] - 2026-11-19

### Added

- Collect Pilot Inventories: all pilot inventories within Teleportation range of the HQ go into its Safe Deposit Storage at once.
- Optional hotkeys for the Safe Deposit Storage and for the selected ship's pilot inventory.
- Debug Level option in the Extension Options.

### Changed

- Requires the game version 8.00 or newer and the `Print Extension List`.

### Fixed

- Context menu: the Teleportation range limit was not enforced.
- An object in a sector unreachable by gates counted as within the Teleportation range.

## [1.02] - 2025-07-19

### Added

- Added context menu support, `if` the of any kind of `X4 Mod Support APIs` is installed.

## [1.01] - 2025-06-16

### Changed

- Improved debug logging, for resolving of possible issues with the extension.

## [1.00] - 2025-06-15

### Added

- Initial release of the Remote Access to Safe Deposit Storage and Pilot's Inventories extension.
